# Bennetfabian Uncut

## How do I install these formulae?

`brew install bennetfabian/uncut/<formula>`

Or `brew tap bennetfabian/uncut` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "bennetfabian/uncut"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
